# Dev-Workbench

> 开发者自用工作台 - 项目管理和 AI 辅助工具

## ✨ 特性

- 📁 **项目隔离**: 支持多层级子模块，无限嵌套
- 💬 **智能对话**: 对接 Hermes Agent，支持 tool_calls
- ✅ **任务管理**: 创建、状态切换、AI 自动拆解
- 📝 **备忘录**: 作为永久记忆，自动注入上下文
- 🔧 **工具调用**: 文件读写、Shell 命令、代码搜索

## 🚀 快速开始

### 安装

```bash
git clone <repository>
cd Dev-Workbench
chmod +x install.sh
./install.sh
